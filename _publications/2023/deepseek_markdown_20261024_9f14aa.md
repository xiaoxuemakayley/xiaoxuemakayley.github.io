title: "ATTSUM: A Deep Attention-Based Summarization Model for Bug Report Title Generation"
selected: true
pub: "IEEE Transactions on Reliability (TR)"
pub_date: "2023"
abstract: >-
  This paper proposes ATTSUM, a deep attention-based summarization model to automatically generate high-quality bug report titles. By employing an encoder-decoder framework with a robustly optimized BERT approach, a stacked transformer decoder, and a copy mechanism, ATTSUM effectively captures contextual semantics and resolves the rare token problem. Evaluations on over 333,000 bug reports demonstrate that ATTSUM significantly outperforms state-of-the-art baselines in both automated metrics and human evaluations.
